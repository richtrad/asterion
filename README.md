# Retired Asterion working portal

The redundant working site at `richtrad.github.io/asterion` was retired on
12 November 2026, after a complete content and Git-history comparison with WOA.
Only a redirect to <https://worldofasterion.github.io/> remains here.

The exact former state (862 files, 237,314,768 bytes) is retained in
[the WOA archive branch](https://github.com/worldofasterion/worldofasterion.github.io/tree/archive/richtrad-asterion-2026-11-12),
at commit `6aae5a98b5e4b6e5ea0afea19f5c1fe5f7a72e00`.

All 859 unchanged files are also present byte-for-byte in the active WOA tree.
The three older frontend files are retained in WOA history and in the archive.
No Git history or repository was deleted or rewritten. The active WOA branch
and the original `asterionrpg.cz` website were not changed by this retirement.
